# 📝 React Redux Todo App 🚀

A simple and responsive *Todo Management Application* built using *React.js* and *Redux Toolkit*. 💙

This project demonstrates how Redux can be used to manage global application state and perform complete CRUD operations. ⚡

---

## ✨ Features

- ➕ *Add Todo*
- 📋 *Display Todo List*
- ✏️ *Edit Todo*
- 🗑️ *Delete Todo*
- ✅ *Update Todo Status*
- 🔍 *Filter Todos*
- 🎯 *Completed / Not Completed Status*
- 🧹 *Clear Input After Adding Todo*
- ⚡ *Global State Management using Redux Toolkit*
- 📱 *Responsive UI*

---
